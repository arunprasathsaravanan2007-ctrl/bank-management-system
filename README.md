# Bank Management System

This is a simple Bank Management System developed using C++.

## Features

* Create Account
* Display Accounts
* Search Account
* Deposit Money
* Withdraw Money
* Check Balance
* Delete Account

## Concepts Used

* C++
* Classes and Objects
* File Handling
* Menu Driven Programming

Customer account details are stored in a file so that records are available even after the program is closed.
